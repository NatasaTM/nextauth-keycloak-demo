## About

This repository demonstrates secure authentication with **Next.js 15**, **NextAuth.js**, and **Keycloak**.  
It is designed as a companion frontend for the [Spring Boot + Keycloak BFF](https://github.com/NatasaTM/springboot-keycloak-bff).
